# Portfolio — Pape Djibril Sène

Développeur Full-Stack & IoT. Stack : Next.js 14 (App Router), TypeScript, Tailwind CSS, Framer Motion.

## Démarrer en local

```bash
npm install
npm run dev
```

Ouvrez http://localhost:3000

## Où sont les choses

- `lib/data.ts` — tout le contenu réel (profil, projets, distinctions, stack). Modifiez ce fichier pour changer les textes sans toucher au design.
- `app/globals.css` + `tailwind.config.ts` — le design system (couleurs, typographies, composants `.pad-label`, `.trace-line`, `.btn-primary`...).
- `components/` — sections de la page d'accueil.
- `app/kaaraange/page.tsx` — case study Kaaraange (étape suivante).

## Placeholders à remplacer

Ce projet ne contient aucune image inventée. Ajoutez vos vrais visuels ici :

- `public/images/kaaraange/` — photos du prototype, schéma d'architecture
- `public/favicon.ico` — favicon du site
- `app/layout.tsx` — remplacez `siteUrl` par votre nom de domaine réel une fois déployé
